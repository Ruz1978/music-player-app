# 🎵 Music Player App

Welcome to the **Music Player App**! This is a simple Java-based console application that simulates the basic features of a music player.

The project is designed to practice **Java programming, Object-Oriented Programming (OOP), collections, and menu-driven applications**.

## 🚀 Features

- ▶️ Turn on the music player
- 🎵 Play the current song
- ⏭️ Play the next song
- ⏮️ Play the previous song
- 🔁 Replay the current song
- 📋 Display all songs in the playlist
- ⏱️ View song titles and durations
- ❌ Delete the current song
- 🎶 Manage songs in a playlist
- 📌 Menu-driven console interface

## 🛠️ Technologies Used

- **Java**
- **Object-Oriented Programming (OOP)**
- **ArrayList / Collections**
- **Console-based interface**
- **Eclipse / Java IDE**

## ▶️ How to Run

### Using Eclipse

1. Open **Eclipse**.
2. Import the project.
3. Open the Java source files inside the `src` folder.
4. Find the main class.
5. Run it as a **Java Application**.
6. Follow the options displayed in the console.

### Using Command Line

Compile the Java files:

```bash
javac *.java
```

Run the main class:

```bash
java SongPlaylistApp
```

> The main class may vary depending on the project structure.
